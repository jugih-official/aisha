Bash-compatible shell

Plain-language requests translated to shell commands

ai$ha (ai shell hybrid alpha, installed as aisha) is a bash-compatible shell that also accepts requests in plain English. Requirement: a stock Debian system. No cloud service or API key is used.

Getting Started Repository

Plain-language requests

Examples: find files older than 2 months, show free on usb, list files by size. The interpreted command is printed, deletes require confirmation, and bash commands are passed to bash unchanged.

No model required

A deterministic rule engine handles several hundred kinds of request: files, text, archives, git, processes, services, packages, network, USB drives. An optional small local model is consulted only when the rules are unsure.

Confirmation before changes

Commands that delete or change data list the affected items and require [y/N]. "Delete everything except report.pdf" keeps report.pdf; "reboot nginx" restarts the service, not the computer.

Bash compatibility

Bash commands, pipes, cd, aliases, jobs and Tab completion work as in bash, so aisha is usable as a login shell. A Debian package is included.
