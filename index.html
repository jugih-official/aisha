Terminal Productivity

Use plain language. Get real shell results.

ai$ha (ai shell hybrid alpha, started as aisha) is a shell you can talk to. Type bash as usual, or say what you want in plain words. It runs on a stock Debian system with no cloud and no API key.

Get Started View Repository

A shell that understands words

find files older than 2 months, show free on usb, list files by size: aisha shows the command it understood, asks before anything that deletes, and runs real bash unchanged.

No model needed

A deterministic rule engine handles hundreds of kinds of request: files, text, archives, git, processes, services, packages, network, USB drives. An optional small local model helps only when the rules are unsure.

Safe by default

Anything that deletes or changes things lists what it will touch and asks [y/N]. "Delete everything except report.pdf" keeps report.pdf; "reboot nginx" restarts the service, not the computer.

A real shell

Bash commands, pipes, cd, aliases, jobs and Tab completion work as usual, so aisha can be your login shell. Debian package included.

Built for fast Linux workflows. See usage and install details on the Getting Started page.
