Getting Started

Install once and start asking for shell tasks in plain words.

Install

git clone https://github.com/jugih-official/aisha.git
cd aisha
packaging/debian/build-deb.sh
sudo apt install ./dist/aisha_*_all.deb

Or ./install.sh, which puts aisha in /usr/local and asks nothing. Needs Python 3.9+ (Debian 11 or newer).

Quick usage

aisha
find files older than 2 months
list all files here by size
show free on usb
delete everything except report.pdf

aisha prints what it understood before running. aisha -n … or "how do I …" only shows the command.

Update and remove

./update.sh
./uninstall.sh

update.sh pulls the latest version and reinstalls it the way you installed it. uninstall.sh asks before deleting your settings in ~/.config/aisha.
