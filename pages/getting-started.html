Getting Started

Install once and start asking for shell tasks in natural language.

Install

./install.sh

The installer places aisha and the ai tools in /usr/local/bin and can optionally configure browser tools. On Debian you can build a package instead: packaging/debian/build-deb.sh.

Quick usage

aisha
find files older than 2 months
list all files here by size
show free on usb

Start aisha and talk to it, or use the one-shot ai tool:

ai list all files in cwd
ai how much RAM is free
ai search the web for the latest python release

Use -n for dry-run and -v for verbose fetch details.

API key lookup order

  1. ANTHROPIC_API_KEY
  2. ~/.config/ai-bash/anthropic-api-key
  3. /etc/ai-bash/anthropic-api-key
