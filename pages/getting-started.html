Getting Started

Installation, usage, update and removal.

Installation

git clone https://github.com/jugih-official/aisha.git
cd aisha
./install.sh

On Debian and Ubuntu, the Debian package is built and installed with apt; on other systems (or with --local), aisha is installed to /usr/local. Requirement: Python 3.9+ (Debian 11 or newer).

Usage

aisha
find files older than 2 months
list all files here by size
show free on usb
delete everything except report.pdf

The interpreted command is printed before execution. aisha -n … and "how do I …" only print the command.

Update and removal

./update.sh
./uninstall.sh

update.sh pulls the latest version and reinstalls aisha in the same way as before. uninstall.sh asks before settings in ~/.config/aisha are deleted.
